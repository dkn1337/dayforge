# DayForge Desktop

- Stack: Next.js App Router, React, TypeScript strict, Tailwind CSS, Tauri 2.
- Zachowuj premium dark UI oraz polską lokalizację.
- Nie dodawaj danych użytkownika na stałe poza demonstracyjną nazwą Karol.
- Przed zmianą backendu przeczytaj dokumentację Supabase i utrzymuj RLS.
- Po zmianach uruchom: `npm run check`.
- Dla desktop builda używaj: `npm run tauri:build`.
